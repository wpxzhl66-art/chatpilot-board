私信回复，有人替你先想好

装在自己电脑上的浏览器插件。打开 TikTok 或 抖音 的私信页，它会读取当前会话， 按你的人设一次给出 5 条风格不同的中文回复；挑一条，看一眼译文，粘贴发送即可。

它能帮你做什么

解决私信沟通里最费时间的三件事：想说什么、怎么说像人话、怎么译得准。

💬
5 条中文候选 读完最近对话，一口气给 5 条风格各异的回复，不用对着输入框发呆。
🎭
多套人设 身份、语气、长短、禁忌都能设。不同账号不同人设，候选风格一键切换。
🌐
发送前翻译 候选永远先给中文（你看得懂、能改），发出前才译成对方语言，译文可微调。
🧭
自动判断对方语言 区分「粉丝说的」和「我说的」，按粉丝最新一条发言定语种，不再译错语言。
📚
话术库 把你的高频话术分组存好，搜索一键取用；AI 生成时也会参考这些话术的风格。
🪟
不遮挡聊天 面板挂在浏览器边缘或独立小窗，页面只留一个可拖动的迷你状态点。

三步装好

只做一次。装好后打开私信页就能用。

  1. 下载并运行安装包点下面的下载按钮拿到 ChatPilotSetup-3.0.6.exe，双击一路「下一步」。装到用户目录，不需要管理员密码（SmartScreen 提示时点「更多信息 → 仍要运行」，因为安装包没有购买代码签名证书）。
  2. 重启浏览器完全退出并重新打开 Chrome 或 Edge——安装包已通过「外部扩展」机制自动注册，重启后 ChatPilot 会自动出现在扩展列表，不需要开发者模式、不需要手动加载（个别环境没自动出现时，按安装包里的《加载扩展指南》30 秒手动加载即可）。AdsPower 等指纹浏览器请在各自「扩展中心 → 本地安装」上传 ChatPilot.crx。
  3. 填 Key 和客服编号打开 TikTok 私信页，点扩展图标打开侧边栏：到 platform.deepseek.com 免费注册并创建 API Key 粘贴进去，再填一个全团队唯一的客服编号（如 ZHL）。都填完点「测试连接」。
为什么需要你自己的 API Key？插件靠大模型思考，每个人用自己的 Key，费用各付各的，互相不受影响。 一次生成约 1~2 分钱，翻译不到 1 分钱——DeepSeek 首次充 10 元可以用很久。

以后怎么更新

再下载一次新版安装包，双击装上（原地覆盖），重启浏览器就是新版。

  1. 下载上面的新版安装包版本号以按钮上的为准，双击安装，会原地覆盖旧版文件（数据不受影响）。
  2. 重启浏览器自动装载跟着新包走，重启即是新版；用开发者模式手动加载过的机器，到扩展页点一次 ChatPilot 卡片上的「刷新」⟳，再回聊天页按一下 F5。
不会丢任何东西：API Key、人设、话术库、查重记录都存在浏览器和云端里，不在安装目录里——更新不会影响它们。

关于安全与隐私

它不会做什么

不替你按发送键（最后一步的粘贴与发送永远由你亲手完成）； 不上传你的聊天内容到任何服务器；不做批量群发、多账号切换这类操作。 所有配置只保存在你自己的浏览器里。

安装时浏览器会警告，是正常的

它是未上架应用商店的本地扩展，所以浏览器会提示「可能不安全」。 代码就在解压出来的文件夹里，随时可查；介意的话先看 src/ 目录再决定是否加载。

候选回复只是建议，发出前请过目。请遵守平台规则，不要用于骚扰或欺诈。
