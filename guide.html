01这是什么

一个装在自己电脑上的浏览器插件，专门帮你「读懂对方在说什么、把回复写得像人话」。

打开 TikTok 或抖音的私信页，插件会读取当前这段对话，按你设定的人设一口气给出 5 条风格不同的中文回复；你挑一条、看一眼译文，粘贴过去就行。

它解决的是三件最费时间的事：

  • 想说什么 —— 候选帮你把话递到嘴边，不用对着输入框发呆；
  • 怎么说像人话 —— 人设兜住语气、长度和禁忌，不会满屏营销腔；
  • 怎么译得准 —— 自动判断对方语言，发出去之前你还能逐句改。
最重要的一条原则：插件只读聊天内容、只写你的剪贴板，从不替你按发送键。 最后一步的粘贴和发送永远由你亲手完成——所以它安全、稳定，也不会触发平台风控。

02五分钟装好

只需要做一次。下面是整个安装动作的示意。

  1. 解压到一个固定文件夹建议 D:\chatpilot。解压后别删、别移动——插件一直从这个文件夹运行。
  2. 打开扩展页并开启开发者模式Chrome 输入 chrome://extensions/；Edge 输入 edge://extensions/。打开右上角（Edge 是左下角）的「开发者模式」。
  3. 点「加载已解压的扩展程序」在弹出的选择框里选中刚解压出来的 chatpilot 文件夹，确定。
  4. 安装成功会弹出设置页若被浏览器拦下，点「允许」即可。提示「可能不安全」是正常的：这是未上架商店的本地插件，代码就在文件夹里，随时可查。

03配好 API Key

插件靠大模型思考，所以需要一个自己的「钥匙」。这一步也只做一次。

  1. 注册并创建 Key打开 platform.deepseek.com → 左侧「API Keys」→ 创建一个，复制出来。
  2. 粘贴到设置页设置页 → 模型设置 → 粘贴 Key。
  3. 点「测试连接」看到「连接成功」就好了。首次充值 10 元，正常能用很久。
费用怎么算：每个人用自己的 Key，费用各付各的，互不影响。 一次生成（5 条候选 + 12 条上下文）约 1~2 分钱，翻译一次不足 1 分钱。 想换成 OpenAI 或 Gemini？在「模型厂商」里切换即可。

05一条回复的完整旅程

从「看到对方消息」到「我发出去了」，一共五步，大约十秒。

为什么最后一步必须我自己来？ 实测 TikTok 对「程序自动写输入框」极其敏感（会弹「出错了」）。所以插件只负责 想内容和把译文放进剪贴板，粘贴与发送交给你——这条路径最稳，也最不容易被平台盯上。

06语种检测是怎么判断的

这是这一版最下功夫的地方：它必须分清「哪句话是对方说的」，才不会译错语言。

它实际按这个顺序做判断

  1. 看粉丝说了什么：取对话栏左边粉丝最近几条非中文发言，以最新一条为准；
  2. 粉丝没说过外语：退回用右边我方消息兜底——此时界面上会橙色明标「我方消息（兜底）」，绝不冒充粉丝消息；
  3. 最新一条看不出语种（纯表情、数字、符号，或混得无法判断）：翻译前弹窗让你选一次目标语言，只对这一次生效。
随时可以自证：侧边栏「实时翻译成」下方那一行会写明本次依据是「粉丝消息」还是「我方消息（兜底）」， 并给出判向台账「对方 N 条 / 我方 M 条」。鼠标悬停能看到每条消息被判成了谁、依据是什么—— 你可以拿它和聊天页面逐条对照。

07人设与话术库

这两个东西决定了「像不像人话」。花十分钟设一次，以后都省心。

人设：让候选说「你会说的话」

设置页 → 人设管理，每套人设填五件事：

字段写什么例子
我是谁身份背景、年龄段、生活状态住在英国的女生，喜欢旅行和美食
语气热情还是克制、口语还是正式热情但不轻浮，偶尔用语气词
说话风格每条多长、什么句式每条 1~2 句，长度和对方最近一条相当
常聊话题能自然展开的方向旅行、美食、日常生活
禁忌不主动碰的内容不主动谈钱；对方索要更多个人信息时礼貌带过

可以建多套人设（例如「英国账号-A」「泰国账号-B」），侧边栏头部一键切换，候选风格立刻不同。

话术库：把你的高频句子存起来

  • 设置页 → 话术库 → 新增分组 / 新增话术；
  • 支持导入文件：.json / .csv / .txt，CSV/TXT 每行一条，格式 中文内容,备注，用 # 分组名 单独一行分隔分组；
  • Excel 表格请先另存为 CSV，或用附带的 tools/xlsx_to_phrases.py 转换；
  • 侧边栏里可搜索、一键取用（同样会翻译）；AI 生成候选时也会参考这些话术的风格。

08Edge 用户的额外一步

如果你用 Microsoft Edge，请务必做这一步——它能让工具不再「时好时坏」。

怎么做：在收到的一键设置文件夹里，双击 1-一键设置Edge-ChatPilot.reg → 一路「是 / 确定」 → 完全退出 Edge（注意右下角托盘图标也要右键关闭）→ 重新打开 Edge 即生效。

想还原：双击 2-还原Edge默认.reg，只删这两项，其他设置分毫不动。

生效后 Edge 设置页可能显示「由你的组织管理」——这是策略生效的正常表现，不是中毒，也不是被谁控制了。 想核对，地址栏输入 edge://policy 就能看到这两条。

用 Chrome 的话没有这两个开关，跳过本节即可。（Chrome 也有后台节流，但没 Edge 这么激进；插件自带的后台看门狗会每分钟主动唤醒一次页面。）

11以后怎么更新

不用再手动解压覆盖。官网提供「一键更新器」，双击一次即可升到最新版。

  1. 把更新器放到插件旁边下载 chatpilot-updater.zip 并解压，把里面三个文件放到与 chatpilot 文件夹同级的位置，例如 D:\chatpilot-install\。
  2. 双击「更新ChatPilot.bat」它会自动比对官网版本：有新版本就下载、校验、备份旧版、覆盖写入；已是最新则直接提示，不做任何改动。
  3. 浏览器里点两下打开 edge://extensions/（Chrome 是 chrome://extensions/），点 ChatPilot 卡片上的「刷新」⟳；再回聊天页按 F5。
为什么不自动升级？这个插件是「加载已解压」的本地扩展，浏览器不为这种安装方式提供自动更新——这是浏览器机制，不是配置问题。 想彻底免掉这一步，需要上架官方扩展商店（Edge 免费 / Chrome 一次性 $5），上架后浏览器约每 5 小时自动检查更新。
要回滚也很简单：每次更新前旧版会自动备份成 chatpilot-backup-v… 文件夹。 把现在的 chatpilot 文件夹删掉，把备份文件夹改名为 chatpilot，回扩展页点一次「刷新」即可。
